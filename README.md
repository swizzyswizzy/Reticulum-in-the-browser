# Reticulum in the Browser

A small appliance that puts a Reticulum / NomadNet node on a Raspberry Pi and exposes it as a web panel.

The Pi joins the mesh, announces itself, hosts a default Micron page, and serves a browser UI on **HTTP port 80** and **HTTPS port 443** (self-signed certificate). No extra desktop stack is required.

Repository: https://github.com/swizzyswizzy/Reticulum-in-the-browser

## What you need

- Raspberry Pi (Zero 2 W is enough)
- microSD card
- [Raspberry Pi Imager](https://www.raspberrypi.com/software/)
- This repository on your computer (for the SD helper)
- The Pi’s address on your LAN after first boot (router DHCP list, or a display if you add one later)

## Flash the card

1. In Raspberry Pi Imager, write **Raspberry Pi OS Lite (64-bit)** to the card. You may set Wi-Fi in the Imager as well; the helper can also write Wi-Fi on the next step.
2. Leave the card in the reader. Do not boot the Pi yet.
3. On your computer:

```bash
cd wizard
pip install -r requirements.txt
python3 rns-imager.py
```

On Windows you can run `rns-imager.bat` instead.

4. Select the boot partition, enter the Wi-Fi network (DHCP), optionally enable auto-install and auto-update, then click **RUN**.
5. Eject the card, insert it into the Pi, and apply power.
6. Wait about 3–5 minutes for first boot (user creation, SSH, clone of this repo, gateway service).

SSH (after first boot):

- user: `rtclm`
- password: `reticulum`
- hostname: `node-xxxxxx` (shown in the helper)

Root password is generated by the helper and shown on screen. Copy it from there.

Open the panel:

```
http://<pi-ip>/
https://<pi-ip>/
```

HTTPS uses a self-signed certificate. The browser will warn once; that is expected.

## Using the panel

The address bar speaks mesh paths, not public DNS:

- `reticulum://home` — start page
- **Nodes** — destinations announced on the mesh; open one to load `/page/index.mu`
- **Messages** — LXMF chat (`lxmf@…` or a 32-character hash)
- **Networks** — enable the home AutoInterface and/or a public TCP hub, then save (the gateway restarts)

On first visit a node serves a placeholder `index.mu` (hostname and repository URL). Pages live under `~/.reticulum-gateway/pages/` on the Pi (`/var/lib/rns/.reticulum-gateway/pages` for the service account).

The footer shows the node hostname and the timestamp of the last software update.

## After first boot

The gateway runs as systemd unit `reticulum-gateway`.

```bash
sudo systemctl status reticulum-gateway
sudo journalctl -u reticulum-gateway -f
```

If **Auto-update** was enabled in the helper, the Pi pulls this repository about once a minute and restarts the service when `master` changes. Log: `/var/lib/rns/update.log`.

Manual install or repair on an already-running Pi:

```bash
sudo bash install.sh
```

## Development

```bash
./start.sh
```

Runs `gateway/gateway.py` in the current tree. Privileged ports 80/443 need root or `CAP_NET_BIND_SERVICE`.

## Layout

| Path | Role |
| --- | --- |
| `gateway/` | HTTP(S) panel, NomadNet page host, LXMF |
| `wizard/rns-imager.py` | Writes first-boot files onto an Imager-prepared card |
| `install.sh` | Clone/update on the Pi, enable systemd |
| `systemd/` | Gateway unit and optional git-update timer |
